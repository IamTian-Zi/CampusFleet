# CampusFleet
CampusFleet 是一个面向校园配送场景的机器人路径规划与调度演示项目。系统以 Python 提供服务端和网页界面，并使用 C++ 实现规划核心；校园地图扩展至 420×280 米，包含建筑、花坛、单向与双向道路、斜向通道及立体桥梁。项目支持多机器人协同规划，通过 CBS 与优先级规划协调路线，并结合等待、减速和移动行人模拟避让。网页和 React Native 客户端可模拟注册、下单、支付与配送进度查询，订单数据由 SQLite 保存。项目还提供 D* Lite 道路变化后的增量重规划演示，展示地图封闭时如何更新路线。室内楼梯、电梯及候梯行人也有简化模拟。CampusFleet 适用于课程展示与算法实验；支付、定位和机器人运动均为模拟功能，不能直接用于真实配送。
